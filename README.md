# ForeverHub

A custom Minecraft launcher for our community.

ForeverHub makes it easier to manage Minecraft profiles and distribute custom modpacks to friends.

### Features
- Manage multiple Minecraft profiles
- Launch Vanilla and Fabric installations
- Separate game directories for each profile
- Microsoft account authentication
- Custom modpack support (work in progress)

### Built With
- Tauri 2
- React
- TypeScript
- Rust

ForeverHub is a personal project developed for friends and is still under active development.
